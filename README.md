# 星脉 · 资源管家

一个深色科技风的 Windows 资源监控与进程管理小工具，使用 C# 和 WPF 编写。

## 功能

- 每 2 秒更新 CPU、物理内存和最近约 2 分钟的实时曲线。
- 按同名进程分组，展示软件图标、CPU、驻留内存和进程数。
- 搜索软件，切换内存或 CPU 排序。
- 查看进程 ID、可见窗口标题与程序路径。
- 请求正常退出，或在确认后强制结束指定进程组。
- 保护系统关键进程、本工具自身及身份无法核实的进程；执行操作前重新验证进程身份。
- 本地运行，无需联网，无自动清理或自动结束操作。

## 构建与运行

环境：Windows 11 x64，以及系统自带的 .NET Framework 4.x 和 64 位 C# 编译器。

在本目录的 PowerShell 中运行：

```powershell
.\编译.ps1
```

编译完成后，双击 `星脉资源管家.exe`。可执行文件已被 Git 忽略，仓库保存源代码与构建脚本。

## 验证

构建后可运行内置自检，输出路径必须使用已有目录中的绝对路径：

```powershell
Start-Process -FilePath '.\星脉资源管家.exe' -ArgumentList '--self-test', ('"{0}"' -f "$PWD\self-test.txt") -Wait
Get-Content .\self-test.txt
```

自检覆盖实时数据采集、界面加载与渲染、自身保护、进程身份变化拦截，并使用专门启动的测试进程验证正常退出和强制结束；同时生成 `preview.png` 界面预览。自检过程中会短暂显示测试窗口。

## 注意

关闭前请保存工作，强制结束可能导致未保存内容丢失。同名进程组可能包含多个独立任务，请核对窗口和进程 ID。内存为驻留内存汇总，包含共享页面，不等于关闭后必然释放的内存量。正常退出可能触发保存提示，后台进程也可能继续驻留。

更多说明见 [使用说明](使用说明.md)。
